RUSTLINE is a round-based tactical FPS: 5v5 bomb plant/defuse on the Rail Yard map, with an economy and buy menu, smoke grenades, bot callouts and a live minimap.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome.
